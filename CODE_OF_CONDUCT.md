# Código de conducta y ámbito de uso

Este proyecto se rige por dos compromisos simples:

1. **Trato respetuoso.** Colaboramos con cortesía, asumiendo buena fe. No se toleran ataques
   personales, acoso ni discriminación.

2. **Uso dentro del ámbito.** Esta herramienta es para investigación de seguridad **defensiva /
   AI-safety** en laboratorios sellados contra objetivos propios. Usarla para acceder, dañar o
   interferir sistemas de terceros sin autorización está fuera del ámbito del proyecto, va contra su
   propósito y muy probablemente contra la ley.

Los mantenedores pueden rechazar contribuciones o cerrar issues que promuevan el uso fuera de ámbito.

Reportes de conducta: abre un issue o contacta al mantenedor del repositorio.
